## **Quick Start**  

### **Installation**  

1. Ensure **Node.js LTS** is installed → [Download Here](https://nodejs.org/en/download/)  
2. Clone the repository:  
   ```sh
   git clone https://github.com/your-repo/tamoagro-finance.git
   cd tamoagro-finance-dashboard
   ```
3. Install dependencies:  
   ```sh
   npm install  # OR yarn install
   ```
4. Start the development server:  
   ```sh
   npm start  # OR yarn start
   ```
